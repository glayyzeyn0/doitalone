Paylanmış Verilənlər Bazası İdarəetmə Sistemləri (PVBİS)

Arxitektura, Növlər və Praktiki Tətbiq

Hazırladı: Gemini AI

Slayd 1/32

PVBİS Nədir? (Giriş)

Paylanmış Verilənlər Bazası (PVB) fiziki olaraq müxtəlif qovşaqlarda yerləşən, lakin məntiqi olaraq vahid bir sistem kimi fəaliyyət göstərən bazadır.

  • Şəbəkə vasitəsilə əlaqə.
  • Lokal muxtariyyət.
  • Mərkəzi olmayan idarəetmə imkanı.
Slayd 2/32

Praktiki Nümunə: Fraqmentasiya (SQL)

Cədvəli regionlara görə bölmək (Üfüqi fraqmentasiya):

-- Bakı filialı üçün lokal cədvəl yaradılması
CREATE TABLE Satislar_Baku AS
SELECT * FROM Global_Satislar
WHERE region_kodu = 'AZE-10';

-- Bütün regionları birləşdirib görmək
CREATE VIEW Umumi_Baxis AS
SELECT * FROM Satislar_Baku
UNION ALL
SELECT * FROM Satislar_Gence;
Slayd 3/32

PVBİS-in Əsas Növləri

1. Homogen (Eynicinsli)

Bütün qovşaqlarda eyni VBİS (məsələn, hamısı Oracle) istifadə olunur. İdarəetmə asandır.

2. Heterogen (Müxtəlifcinsli)

Fərqli qovşaqlarda fərqli sistemlər (Oracle, MySQL, NoSQL) ola bilər. Gateway tələb edir.

Slayd 4/32

CAP Teoremi və Seçimlər

Paylanmış sistemlərdə eyni anda üç xüsusiyyətdən yalnız ikisi mükəmməl ola bilər:

Xüsusiyyətİzahı
Consistency (Uyğunluq)Hər kəs eyni anda eyni datanı görür.
Availability (Əlçatanlıq)Sistem hər zaman sorğulara cavab verir.
Partition ToleranceŞəbəkə kəsilsə belə sistem işləyir.
Slayd 5/32

Tranzaksiyaların İdarə Edilməsi: 2PC

Two-Phase Commit (2-Fazalı Təsdiq):

  1. Hazırlıq Fazası: Koordinator soruşur: "Hər kəs hazırdırmı?".
  2. İcra Fazası: Əgər hamı "Hə" desə - Commit, biri "Yox" desə - Rollback.

Bu, paylanmış bazalarda məlumatın dürüstlüyünü təmin edir.
